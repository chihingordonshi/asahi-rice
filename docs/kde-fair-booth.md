# KDE fair booth

## Prepare after logging in to Plasma

The desktop uses the dark glass-sphere wallpaper, a floating launcher and task panel at the bottom, and a slim floating top panel with the application menu plus CPU and memory widgets. The bottom panel also has the pager, system tray, clock, and Show Desktop. The wallpaper is a local asset; keep `~/Pictures/Wallpapers/original/glass-sphere.jpg` available on the booth machine.

1. Log out and back in to Plasma after changing the panel files. Confirm the wallpaper and both floating panels appear. The top panel should show CPU and memory activity; the bottom panel should show the launcher, running apps, tray, and clock.
2. Open a terminal and run `~/Projects/asahi-rice/tools/run-kde-fair-showcase.sh`. It stops the Codex Touch Bar service if that service is running, then runs `touchbar play linux-showcase --loop`. Press Ctrl+C to end the loop. The player restores normal Touch Bar controls, and the booth script restarts the Codex service if it was running before the showcase.
3. Keep Dolphin, System Settings, and one creative app ready for visitors. Close private documents and notifications before the booth opens.

## A short visitor walkthrough

1. Start on the desktop: explain that KDE Plasma is the desktop, while names on the Touch Bar include Linux, distributions, and other desktops or compositors.
2. Press **Meta+W** to open Overview. Show the open windows and use its search field to launch an app. Press **Esc** to return.
3. Use the bottom launcher to open Dolphin. Show file previews and split view, then open System Settings to demonstrate the appearance options.
4. Point out the live CPU and memory widgets and the system tray. Let a visitor open Overview or move a window, then return to the original desktop for the next person.

The showcase video is generated by `tools/generate-linux-showcase-touchbar.py` at 2008×60, 30 fps, FFV1. Regenerate it with `python3 tools/generate-linux-showcase-touchbar.py`. Its 28 words take 33.6 seconds before looping, with a new center word every 1.2 seconds.
